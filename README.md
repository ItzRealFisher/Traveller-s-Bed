# Traveller's Bed

Paper 26.2 plugin for reusable beds that retain the player's existing respawn point. Build with `scripts\\build-plugin.bat`; deploy and run with `scripts\\rebuild-and-start.bat` after accepting the Minecraft EULA.

Recipe: one ordinary bed of any colour plus one oak log, shapelessly, in 2x2 or 3x3 crafting. The output preserves the bed colour.
